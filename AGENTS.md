# AGENTS.md — VetCrewMain

> **Спершу прочитай [PROJECT-CONTEXT.md](PROJECT-CONTEXT.md).** Там зафіксовано архітектурні інваріанти за каноном v10: адресація на спільному домені `alik532ua.github.io/VetCrew/`, префікси сховища `vetcrew_`, SEO, політика безпеки (CSP), доступність та модель версіонування. Цей файл — практична витримка для повсякденної роботи агентів.

---

## 1. Що це за проєкт

Офіційний інтерактивний веб-портал організації **Vet Crew** (`https://alik532ua.github.io/VetCrew/`).

- **Основні функції**: головна вітрина організації, динамічне векторне 3D-лого Vet Crew на сітці координат 970 з фізикою реакції на курсор та гіроскоп, панель офіційних каналів допомоги (Donate, Instagram, модальне вікно Info), панель перемикання теми (темна/світла), мови (UA/EN) та повноекранного режиму.
- **Стек**: SvelteKit 2 + Svelte 5 (Runes), TypeScript 6, `@sveltejs/adapter-static`, CSS Variables.
- **Хостинг**: GitHub Pages під базовим шляхом `/VetCrew` на спільному домені `alik532ua.github.io`.

---

## 2. Ключові архітектурні інваріанти

1. **Svelte 5 Runes (виключно):**
   - Використовувати тільки `$state`, `$derived`, `$props`, `$effect`, snippets. Жодного синтаксису Svelte 4 (`let:`, `export let`, `$:`, `<slot>`).
2. **Сховище на спільному домені (STORAGE-NAMESPACE-v10):**
   - Префікси сховища: `vetcrew_` (prod), `vetcrew-dev_` (dev).
   - Пряме звернення до `localStorage` повз узгоджені сервіси заборонено.
3. **Безпека (CSP & XSS):**
   - Усі інлайн-скрипти в `src/app.html` автоматично хешуються SHA-256 у `svelte.config.js` з нормалізацією CRLF -> LF. Інваріант перевіряється тестом `src/csp-hash.test.ts`.
   - Вставка Schema.org (`NGO`) виконується суворо через безпечну функцію `jsonLdScript()` (`src/lib/security/jsonLd.ts`), що екранує `<`, `>`, `&` та Unicode-розділювачі.
4. **Доступність (WCAG 2.2 AA):**
   - Усі кнопки й посилання мають висококонтрастний видимий контур `:focus-visible`.
   - Автоматична зупинка коливань 3D-логотипу при системному `prefers-reduced-motion`.
5. **Обробка помилок (Error Boundaries):**
   - Контент у `src/routes/+layout.svelte` огорнутий у `<svelte:boundary>`.
   - Клієнтський хук `src/hooks.client.ts` логує контекст помилок та перезавантажує сторінку при застарілих чанках (`chunkMissing`).

## 3. Локальні пастки

| Пастка                       | Що врахувати                                                                                                                                                      |
| :--------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Базовий шлях `/VetCrew`**  | У production сайт розгортається у підтеку `/VetCrew`. `paths.relative: false` у `svelte.config.js` гарантує абсолютну адресацію. Не хардкодь базові шляхи вручну. |
| **Нормалізація CRLF у CSP**  | Будь-які зміни в `src/app.html` змінюють SHA-256 хеш. Обов'язково запускати `npm run test:unit` для перевірки відповідності хешів.                                |
| **Автоматичний бамп версії** | Pre-commit хук Husky автоматично викликає `scripts/bump-version.mjs`. Не змінюй версію в `package.json` вручну при поточній роботі.                               |

---

## 4. НЕ РОБИ

- **НЕ** додавай інлайн-скрипти до `src/app.html` без перевірки та поновлення CSP SHA-256 хешів.
- **НЕ** використовуй сторонні UI-фреймворки; дизайн базується на чистих CSS-змінних бренду та `lucide-svelte`.
- **НЕ** використовуй відносні шляхи в посиланнях або ресурсах (`paths.relative: false`).
- **НЕ** послаблюй strict-режим TypeScript (`strict: true`, `noUncheckedIndexedAccess: true`).
