# Vet Crew 🐾

Офіційний інтерактивний веб-портал благодійної організації **Vet Crew**.

## ✨ Огляд проєкту

- 🌀 **Динамічне 3D лого**: інтерактивна фізика нахилу від миші та гіроскопа смартфонів, спекулярний відблиск та дихаюча анімація.
- 📜 **Інтерактивні канали**:
  - Офіційний Instagram (`https://www.instagram.com/vet.crew/`).
  - Підтримка та донати (`https://vet-crew-donation.org`).
  - Інформаційне вікно розробки сайту.
- 🌓 **Теми**: світла та темна теми з плавним переходом.
- 🌐 **Двомовність**: українська (UA) та англійська (EN).
- ⚡ **Технології**: SvelteKit 2, Svelte 5 Runes, TypeScript, adapter-static.

## 🚀 Запуск та розробка

```bash
# Встановлення залежностей
npm install

# Запуск dev-сервера
npm run dev

# Перевірка типів та коду
npm run check

# Аудит залежностей
npm run audit:ci

# Збірка для публікації
npm run build
```
