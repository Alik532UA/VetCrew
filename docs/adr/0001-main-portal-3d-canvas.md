# ADR 0001: Архітектура головного порталу організації та 3D векторного логотипу

## Статус

Прийнято

## Контекст

Організація Vet Crew потребує центральної точки присутності (веб-порталу), що об'єднує всі напрями діяльності: невідкладну допомогу, госпіталь, збір донатів та офіційні канали комунікацій. Інтерфейс має бути виразним, технологічним та адаптивним для будь-яких типів екранів.

## Рішення

1. Створити легкий високопродуктивний статичний SPA на базі SvelteKit 2 та Svelte 5 Runes.
2. Реалізувати інтерактивний центральний елемент — фірмовий логотип Vet Crew на нормалізованій векторній сітці координат 970 із динамічною реакцією на курсор миші (десктоп) та нахили пристрою (мобільний гіроскоп).
3. Забезпечити підтримку `prefers-reduced-motion`: при системному увімкненні зменшеного руху анімація коливань вимикається.
4. Оснастити портал швидкими каналами взаємодії: Donate (`vet-crew-donation.org`), Instagram (`instagram.com/vet.crew`), модальним інформаційним блоком про поточні етапи розвитку організації та панеллю керування (мова, тема, повний екран).

## Наслідки

- Миттєве завантаження без використання важких 3D-движків.
- Повна доступність (WCAG 2.2 AA) з висококонтрастними контурами фокусу.
